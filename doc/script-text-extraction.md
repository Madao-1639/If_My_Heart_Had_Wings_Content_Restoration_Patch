# 脚本文本提取与匹配验证

## 1. 提取方法

### 1.1 文本来源

**Rio.arc**（50,990 条文本）：
- 主要游戏脚本存储在 `Rio.arc` 中
- 包含所有常规剧情对话

**RIO目录**（7,277 条文本）：
- 位于 `游戏目录/RIO/` 下的独立脚本文件
- 包含特殊场景（H场景等）和补充内容
- 文件列表：CO1_001.ws2, CO1_002.ws2, CO1_003.ws2, CO1_015.ws2, HUT_004.ws2, HUT_005.ws2, SL_AGE_001.ws2, SL_AMA_001.ws2, SL_HUT_001.ws2, SL_KOT_001.ws2, start.ws2

**总计**：58,267 条文本，49,922 个唯一CRC32

### 1.2 对话行格式

```
\x14 <idx:u16> <flag:u16> char\x00 <Shift-JIS对白> %K%P|%P|%K
```

**正则表达式**：
```python
DIALOGUE_PATTERN = re.compile(
    rb'\x14(.{2})(.{2})char\x00((?:[\x80-\xff\x00-\x7f])*?(?:%K%P|%K(?!%P)|(?<!%K)%P))',
    re.DOTALL
)
```

**CRC32 计算方法**：
1. 提取文本部分（包含 %K、%P 标记）
2. 使用 cp932 解码为 Unicode 字符串
3. 转换为 UTF-16LE 编码
4. 计算 CRC32（有符号 int32）

```python
def calc_crc32(text_str):
    text_utf16le = text_str.encode('utf-16le')
    crc_unsigned = zlib.crc32(text_utf16le) & 0xffffffff
    if crc_unsigned >= 0x80000000:
        return crc_unsigned - 0x100000000
    return crc_unsigned
```

## 2. 匹配验证结果

### 2.1 双向验证方法

**正向验证**（提取的原版日文文本 → 民汉表）：
- 检查我们提取的每条文本是否在民汉表中有对应译文
- 评估提取质量：确保我们提取的是有效的游戏文本

**反向验证**（民汉表 → 提取的原版日文文本）：
- 检查民汉表中的每条译文是否能在我们提取的文本中找到对应日文
- 评估覆盖率：确保民汉译文能被充分利用

### 2.2 验证结果

| 验证方向 | 结果 | 说明 |
|---------|------|------|
| 正向（提取 → 民汉） | 99.996% (49,920/49,922) | 我们提取的文本几乎全部有译文 |
| 反向（民汉 → 提取） | 99.760% (49,920/50,040) | 民汉表的译文覆盖率 |
| 未匹配 | 120 条 (0.24%) | 民汉表中有120条译文在当前脚本中无对应 |

**结论**：99.76% 的高覆盖率证明提取方法正确且完整。

## 5. 提取工具使用

提取工具位于 `tool/extract_script_text.py`，可提取并解析 WS2 脚本中的对话行。

**输出格式**（JSON）：
```json
{
  "script_name": "脚本名称",
  "texts": [
    {
      "lng_idx": "索引号",
      "text": "纯对话文本（不含角色名）",
      "text_with_name": "带角色名的完整文本（如有）",
      "char_name": "角色名（不含%LC前缀，如有）"
    }
  ]
}
```
